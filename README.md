# Creating the Optimal Pokemon Team
This is archived code from a fun weekend project I did in 2021 to celebrate the release of Pokemon Brilliant Diamond and Pokemon Shining Pearl, where I wrote an optimization model that determined the best team of Pokemon to use in a playthrough. The constraints were the in-game limitations of carrying up to 6 Pokemon with you at a time, plus having one of these Pokemon be one of the three starter Pokemon you choose from at the start of the game. Using their elemental types and types the main bosses you fight in the game specialize in, I wrote an optimizer that determined the ideal team of Pokemon to use. This code is tailored to the roster of Pokemon available in the aforementioned games, but can be easily adjusted to Pokemon found in other games.
